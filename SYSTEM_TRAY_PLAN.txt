### 2.2 修改 `_on_close()` — 点击 X 时的行为

**当前代码：**
```python
def _on_close(self) -> None:
    self.withdraw()
    self._append_log("⚠️ 已最小化到后台")
    return
```

**修改为：**
```python
def _on_close(self) -> None:
    self.withdraw()  # 隐藏窗口，但进程继续在托盘运行
    self._append_log("⚠️ 已最小化到系统托盘，可通过托盘图标或 python main.py 重新打开")
    self._setup_tray()  # 创建托盘图标
```

### 2.3 新增托盘相关函数

```python
def _setup_tray(self) -> None:
    """创建系统托盘图标"""
    icon_path = Path(__file__).parent / "icon.png"
    icon_image = Image.open(icon_path)

    def on_double_click(state, app=self):
        app.after(0, app.show_window)

    def on_quit(state, app=self):
        app._ipc_stop_event.set()
        app.destroy()

    def create_menu():
        def show_window(icon, item):
            self.after(0, self.show_window)
        def disconnect_now(icon, item):
            from stop import disconnect_and_stop
            disconnect_and_stop()
        def quit_app(icon, item):
            self._ipc_stop_event.set()
            self.destroy()

        return pystray.Menu(
            pystray.MenuItem("显示主窗口", show_window),
            pystray.MenuItem("立即连接", lambda i, item: self.after(0, self._on_connect)),
            pystray.MenuItem("断开连接", disconnect_now),
            pystray.MenuSeparator(),
            pystray.MenuItem("退出", quit_app),
        )

    self._tray = pystray.Icon(
        "srun_login",
        icon_image,
        "校园网自动登录工具",
        create_menu(),
    )
    self._tray.run_detached()  # 在后台运行托盘，不阻塞

def show_window(self) -> None:
    self.deiconify()
    self.lift()
    # 如果托盘图标存在，可以销毁它（用户重新打开了窗口）
    if hasattr(self, "_tray"):
        self._tray.stop()  # 停止托盘
        self._tray = None
```

## 四、托盘图标的连接状态更新（可选）

当连接状态变化时（连接成功 / 断开），托盘图标的 tooltip 或菜单文字也应该更新：

```python
def _update_tray_status(self, status_text: str) -> None:
    """更新托盘提示文字"""
    if hasattr(self, "_tray") and self._tray is not None:
        self._tray.title = f"校园网自动登录 - {status_text}"
```

在 `_set_status()` 和 `_on_connect()` 等函数中调用这个方法。

## 六、注意事项

1. **托盘图标不阻塞主线程**：`pystray.Icon.run_detached()` 必须在后台运行，不要用 `run()`（会阻塞）

2. **退出时清理托盘**：调用 `self._tray.stop()` 确保托盘图标消失

3. **Windows 任务栏图标**：双击窗口标题栏的图标也可以最小化到托盘（这个是 customtkinter 默认行为，不需要额外处理）

4. **Linux 下托盘**：需要系统有托盘支持（如 GNOME/KDE 的 notification area），如果 Linux 没有托盘环境，`_setup_tray()` 应该失败后优雅降级（打印警告但不崩溃）

## 七、托盘功能效果

| 操作 | 结果 |
|------|------|
| 点击窗口 X | 窗口消失，托盘出现 WiFi 图标 |
| 双击托盘图标 | 窗口重新显示，托盘消失 |
| 右键托盘 → 显示主窗口 | 同上 |
| 右键托盘 → 退出 | 程序完全退出 |
| 右键托盘 → 断开连接 | 执行 logout 并停止所有任务 |
