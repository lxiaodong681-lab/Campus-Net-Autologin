## 🎯 项目简介

本工具用于自动化登录采用 **深澜软件（Srun/BigSrun）** 认证系统的校园网。

> **适用范围说明**：本工具不局限于任何特定学校。江西师范大学仅作为配置示例。任何使用深澜 Srun Portal 认证系统的校园网环境均可使用，只需填入对应网关地址和 `ac_id` 参数即可。

### 功能特性

- **自动化登录** — 调用 Srun Portal API 完成身份认证，支持登录 / 登出 / 在线状态查询
- **跨平台支持** — Windows · macOS · Linux
- **图形界面** — CustomTkinter 可视化配置，开箱即用
- **安全存储** — 密码存入操作系统原生密钥链（Keyring），不以明文落盘
- **开机自启** — 注册系统自启项，开机自动静默联网
- **请求限频** — 内置合理请求间隔，避免对认证服务器造成压力

### 适用场景

- 多设备需要手动打开网页登录的桌面环境
- 希望开机后自动保持网络连接，无需人工干预
- 将账号密码安全托付给系统密钥链而非明文配置文件

## 📦 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动图形界面（首次运行会弹出配置向导）
python main.py

# 静默登录（用于开机自启脚本）
python main.py --background
```

### 常用启动参数

| 参数 | 说明 |
|------|------|
| `--minimized` | 启动后最小化到系统托盘 |
| `--background` | 后台静默登录，登录完成后自动退出 |
| `--configure` | 强制显示配置界面（用于修改账号或网关）|
| `--quit` | 通知已运行的实例退出 |

## ❓ 常见问题（FAQ）

### 1. 程序启动时报 `ModuleNotFoundError`
- **原因**：依赖未安装或虚拟环境未激活
- **解决方案**：确保已执行 `pip install -r requirements.txt`，并使用正确的 Python 环境

### 2. 程序启动后立即退出或无法启动
- **原因**：配置目录不可写或日志目录无法创建
- **解决方案**：检查当前用户对项目目录的写入权限，必要时更换安装路径

### 3. 登录流程一直失败且无明确提示
- **原因**：网关地址不可达或网络异常导致关键请求超时
- **解决方案**：核对网关地址，确认设备已连接校园网（有线/无线）后重试

### 4. 密钥链不可用，无法保存账号密码
- **原因**：系统密钥链服务未启动或权限不足
- **解决方案**：启动系统密钥链服务后重试，或重启系统

### 5. 请求频率过高导致服务器拒绝
- **原因**：短时间内多次调用 login接口，触发了服务器的限频策略
- **解决方案**：程序内已内置请求间隔；若问题持续，请检查是否有其他登录脚本在并行运行

## 🔐 安全说明

1. **密码不落盘**：账号密码通过 OS 原生密钥链管理，不写入配置文件或代码
2. **Token 一次性**：每次登录请求使用服务器下发的随机 `challenge` token，密码不直接传输
3. **请求限频**：所有 HTTP 请求均设置超时，并在关键步骤间插入延迟，避免对认证服务器造成压力
4. **请勿硬编码**：部署前请确认代码中没有遗留任何账号密码信息，并已将敏感配置文件加入 `.gitignore`
