# 江西师范大学校园网自动登录

Windows 托盘程序，面向**江西师范大学中国移动校园网**。进入 Windows 桌面后自动检查校园网认证状态，掉线后重新登录，夜间停网时等待恢复。

本版用 C# / .NET 8 Windows Forms 重写原 Python 实现。当前支持 **Windows 10/11 x64、江西师大移动线路**；不再提供原版 macOS/Linux、通用网关配置或 Python 命令行功能。认证入口为 `http://172.17.1.2`，`ac_id=1`，账号后缀为 `@cmcc`。

## 安装与使用

从 [Releases](https://github.com/lxiaodong681-lab/Campus-Net-Autologin/releases) 下载 Windows x64 版本：单文件 `CampusAutoLogin.exe` 可直接运行；希望自动创建桌面快捷方式及注册自启动时，请下载并完整解压安装包 ZIP。预发行版对应重写后的新实现，旧 Python 发行版不适用本文说明。

也可从本仓库 Actions 中成功的 **Windows build and test** 运行下载 `CampusAutoLogin-win-x64` 制品，或按下文从源码构建。

在解压目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本将程序复制到当前用户目录，创建桌面“江西师大校园网”快捷方式，注册登录 Windows 后自动运行，并通过任务计划程序启动后台实例。双击桌面快捷方式或托盘图标进入设置。无需管理员权限，也无需另外安装 .NET 运行时。

1. 输入自己的校园网账号和密码，点击“保存并启用”。账号可以不带 `@cmcc`。
2. 保持“登录 Windows 后自动运行”勾选。关闭窗口后程序继续在托盘运行。
3. 双击托盘图标打开设置；右键可立即检查、查看日志或退出。已保存密码时，密码输入框留空可保留原密码。

程序只在活动有线或无线网卡的 IPv4 地址和网关属于当前支持的江西师大 10.128.0.0/15 接入网时访问认证服务器；请求绑定校园网网卡，门户还需匹配江西师大与移动标识。外部网络下待机，不发送认证请求。网络切换会触发重新检查；学校更换地址范围时需要更新识别规则。程序使用 Windows 已连接的校园网，不新建 Wi-Fi 配置。无线用户应先连接校园 Wi-Fi，并启用 Windows 的自动连接。

## 工作方式

- 已在线时每 60 秒查询一次学校认证状态，不重复提交登录，也不注销现有会话。
- 离线时从学校登录页获取当前 IP，再获取挑战码，按深澜协议计算认证参数并登录。不会沿用上一次 DHCP 地址。
- 网络或认证服务暂时不可用时，按 20、40、80、160、300 秒逐步延长重试间隔，最长间隔 5 分钟。校园网恢复后继续尝试。
- 明确的账号、密码、欠费或绑定错误会暂停提交并弹出托盘提示；修正后保存或点击重试。
- 单实例运行；重复启动时提示从托盘打开设置。

“校园网已在线”表示学校认证服务器报告在线，不代表运营商外网一定正常。夜间学校停网期间本程序无法提供网络。自启动发生在**登录 Windows 后**，不是 Windows 登录屏幕前。

## 本地数据与卸载

程序位于 `%USERPROFILE%\JxnuCampusAutoLogin`，配置与日志位于该目录下的 `data` 文件夹，避免打包应用的 AppData 虚拟化：

| 文件 | 用途 |
| --- | --- |
| `CampusAutoLogin.exe` | 自包含单文件程序，无需预装 .NET；首次启动会将原生运行库解包至 .NET 临时缓存 |
| `settings.json` | 账号与 Windows DPAPI 加密的密码 |
| `activity.log`、`activity.log.1` | 轮转状态日志，不记录账号、密码或完整认证请求 |

DPAPI 按当前 Windows 用户保护密码；同一用户权限下的程序仍可能解密，不应分享配置文件。网络侧沿用学校现有 HTTP 门户及挑战认证协议。

自启动使用 Windows 任务计划程序中的 `JxnuCampusAutoLogin-<用户 SID>` 任务：当前用户登录后延迟 15 秒，普通权限，不保存 Windows 密码，电池供电也运行，无运行时限，异常退出后每分钟重试最多 3 次。设置中的自启动勾选控制该任务；保存时清理旧注册表启动项。

卸载时先在设置中取消自启动并保存，再从托盘退出，删除安装目录与桌面快捷方式。删除安装目录也会删除保存的凭据和日志。

### 从旧版迁移

先退出旧 Python 版本并取消其自启动，然后安装新版、重新输入凭据。新版不读取或迁移原 Python `%APPDATA%\srun_login` 配置。rc.1 的 DPAPI 配置可由安装脚本从当前可见的旧 AppData 目录迁移，已有新配置不会覆盖。旧实现仍可从 Git 历史获取；本 PR 不修改已有发行版。

## 从源码构建

在 Windows 上安装 .NET 8 SDK 后运行：

```powershell
.\test.ps1
.\build.ps1
.\install.ps1
```

构建产物在 `artifacts/`，首次还原需要访问 NuGet。脚本支持 `-DotnetPath 'C:\path\to\dotnet.exe'`，不依赖开发者本机的 `.tools` 目录。安装前请退出已经运行的新版程序，以免文件被占用。直接运行 EXE 时，启用自启动后请保留 EXE 的所在位置；建议通过安装包固定到用户目录。

## 验证

默认测试不连接校园网，使用虚构账号及固定测试向量，覆盖与校园门户脚本对照的加密结果、JSONP 解析、移动后缀、退避策略、DPAPI 往返、模拟登录请求顺序、动态 IP，以及门户页面变化时停止提交。测试向量最初由学校公开 `Portal.js` 的编码函数及 Node.js 标准密码库生成；不随仓库分发门户脚本。

需要在校园网且已经在线时，可额外执行只读状态测试：

```powershell
.\test.ps1 -Live
```

默认 CI 只运行离线测试与 Windows 自包含构建，不获取真实凭据，不发出真实认证或注销请求。用户本机已完成安装和在线守候验证；离线认证效果仍取决于账号状态、校园网服务及校方协议。
